# AI-Powered HR Interview Preparation Chatbot

## About the Project
An interactive chatbot that helps users practice HR interview questions and improve their interview answers.

## Features
- 10 HR interview questions
- AI-generated feedback for each answer
- Answer scoring
- Suggestions for improvement
- Sample improved answers
- Final performance report

## Technologies Used
- Python
- Gradio
- Google Gemini API
- Google Colab

## How to Run
1. Open the `.ipynb` notebook in Google Colab.
2. Configure your Gemini API key securely.
3. Run the notebook cells.
4. Open the Gradio link generated by the notebook.
5. Answer the interview questions and review your feedback.

## Security
Never share or upload your API key.

## Project Type
Educational project for interview preparation and Python practice.
